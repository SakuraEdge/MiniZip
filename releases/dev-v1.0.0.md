# MiniZip Dev v1.0.0

首个开发发布版本，面向 Windows x64。

## 新增

- 采用已确认的 M 字母应用图标，提供多尺寸 Windows ICO。
- 移除示例压缩包、示例收藏和演示任务，默认使用图标侧栏，可展开文字导航。
- 常用操作直接展示：解压到当前目录、解压到指定目录、删除所选。
- 从外部双击压缩包或“用 MiniZip 打开”进入实际目录。
- 右键文件 / 文件夹“添加到压缩文件…”只打开独立快速压缩窗口，不显示主工作台。
- 支持 ZIP / 7Z 创建、中文密码、压缩级别、保存位置、进度与取消。
- 安装向导提供可选格式关联、右键菜单及 Windows 默认应用设置入口。
- 软件更新页显示 GitHub 发布版本、更新内容和 Dev / Rev 通道；下载后校验 SHA-256，再由用户确认安装。

## 已验证

- ZIP / 7Z / TAR / RAR5 / LZ4 / GZ / BZ2 / XZ / ZSTD 解压，以及 TAR.GZ / TAR.LZ4 容器。
- LZ4 中文及 Unicode 路径不依赖 Windows 系统语言；损坏帧拒绝处理。
- 中文密码 7Z、AES ZIP、传统 ZipCrypto ZIP 解密；中文密码 ZIP / 7Z 创建。
- 同名文件重命名 / 跳过 / 覆盖、取消清理、路径和链接拦截。
- 未加密 ZIP / 7Z / TAR 内部删除并保留原包备份。

## 已知限制

- 开发版本，尚未数字签名；Windows 可能提示未知发布者。
- 不能承诺所有历史压缩格式、加密编码或分卷变体均兼容。
- RAR 等只读格式不支持直接删除包内文件。
- 默认打开方式由 Windows 10/11 系统设置确认，不强改受保护的用户选择。
- Windows 11 的传统右键项可能位于“显示更多选项”。
- 解压上限为 100,000 条目和 128 GiB；不允许符号链接、硬链接、越界路径。
- 压缩与解压支持取消；安全提交阶段不可取消，不支持暂停续传。
- LZ4 首次打开会执行完整性校验，大文件需要等待。
