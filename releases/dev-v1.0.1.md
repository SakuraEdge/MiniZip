# MiniZip Dev v1.0.1

## 界面与图标

- 主工作台和右键快速压缩小窗改用薄荷绿、浅蓝与白色。侧栏、选中项和主要按钮采用同一套配色，删除仍以红色标识。
- 应用和快捷方式保留 M 形拉链标识；关联的 ZIP、RAR、7Z、LZ4 等压缩文件改用 C 款叠页图标，提供 16–256 px 八种 Windows 尺寸。工作台内的嵌套包和快速压缩小窗也使用同一叠页图标。
- [查看应用与压缩文件图标的实际尺寸对照](https://github.com/SakuraEdge/MiniZip/blob/dev-v1.0.1/design/file-icons/dev-v1.0.1.png)。安装后如仍看到其他软件的图标，请在 Windows 默认应用设置中为相应格式选择 MiniZip。

## 新增

- 每个压缩包打开独立工作台，支持外部双击、多选打开、拖入和嵌套压缩包，不再替换原窗口。
- 双击 PDF、文档等文件调用 Windows 默认应用。可执行文件与脚本运行前需确认，并准备相关目录依赖。
- 外部应用保存后，工作台显示修改提示，可保存到压缩包或另存副本；写回前校验，原包保留备份。
- 支持 ZIP / 7Z / TAR 内容写回，覆盖中文密码 AES ZIP、ZipCrypto ZIP 和加密 7Z，保留加密保护。
- 内层压缩包保存后，外层工作台检测改动并提示写回；关闭关联工作台前提醒处理内层窗口。
- Explorer 右键操作归入 MiniZip 子菜单：打开、解压到指定位置、当前文件夹或同名文件夹，以及 ZIP / 7Z 压缩入口。
- 已有压缩包也可再次压缩，默认保留原扩展名形成新的包名，避免覆盖输入。
- 工作副本保留 Windows 下载来源标记，侧栏提供外部工作副本入口。

## 修复与验证

- 窗口之间隔离归档会话、解压授权和任务事件；关闭一个工作台不影响其他窗口。
- 校验原包是否被其他程序修改，拦截过期会话写回；写回时再次校验外部副本。
- 新增未保存关闭确认、编辑器原子保存、嵌套包写回、加密更新、资源管理器命令测试。

## 已知限制

- 本版应用和安装包未做 Authenticode 签名，Windows 可能提示“未知发布者”。请从本仓库的 Release 下载；同页提供 SHA-256 校验文件，校验不能代替发布者签名。
- Windows 11 的聚合右键菜单可能位于“显示更多选项”；未部署需受信任签名的原生首层扩展。
- RAR 等只读格式不能写回，使用“另存副本”保存修改。
- 外部应用另存为新文件、重命名或新增文件不自动加入原包。关闭 MiniZip 后停止监测，但保留工作副本。
- 加密文件外部打开时会产生本机未加密工作副本；首次打开前会确认，可从“外部工作副本”入口查看和清理。
- 文件关联仍由 Windows 默认应用设置确认，不修改受保护的 UserChoice。
