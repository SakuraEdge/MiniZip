# MiniZip Dev v1.0.2

## 包内程序与临时文件

- 双击包内 EXE 后，MiniZip 会先显示临时展开的目录和大小。确认后，程序可以使用同目录及子目录中的配置、DLL 和资源，无需手动解压。
- 程序退出后，没有内容变化就直接清理；有变化则列出新增、修改和删除的文件。选择「更新压缩包」会校验写回、保留原包备份并清理；选择「不更新」只清理本次临时目录，原包保持不变。
- 常见文本、图片和 PDF 默认直接从内存预览，不产生解压副本。需要外部应用时，同一工作台复用临时文件；无法确认文档何时关闭时，可手动选择「结束外部编辑」。旧版 `work-files` 不会被批量删除。

## 文件操作

- 列表和网格均支持按住左键拖动框选、Ctrl 追加选择和边缘滚动。右键已选项目会保留整个选区。
- 工作台右键可直接打开、解压、重命名或删除所选项目。未加密 ZIP、7Z、TAR 支持包内重命名（F2），重名不会覆盖。

## 安装与限制

- Windows x64 开发预发布版。旧版可在「软件更新」开启「接收 Dev 开发版本」后检查更新。安装包未做 Authenticode 签名，同页提供 `.sha256` 校验文件。
- 临时运行不是安全沙箱，只运行来源可信的程序。根目录 EXE 需要临时展开整个包；单次上限为 8,192 项、2 GiB。程序写到注册表、AppData 等目录的内容不参与回写。
- RAR 等只读格式不能写回，可从临时目录另存数据。文件被占用、再次变化或写回失败时，MiniZip 会保留尚未处理的数据。
